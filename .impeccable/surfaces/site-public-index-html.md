# lima.liamhosfeld.com

Mode: Persuade. One page plus llms.txt, robots.txt, sitemap.xml and a 404.

Audience: developers who already run Claude Code, Codex or OpenCode on a Mac. Job: understand in one viewport that Lima is a browser where those agents work visibly, then download. Proof: animated HTML recreations of real Lima UI (demo data, labeled as such). No testimonials or invented claims. Constraints: strict CSP (self-only scripts, styles, images; no remote fonts), system fonts, light and dark, Reduce Motion.

## Direction contract

THESIS: The site is a Lima window. Its left sidebar is the site's navigation: features are sidebar tabs, and the page refuses the category's centred hero over a row of feature cards.

OWN-WORLD: Lima's own chrome: #F2F2F2 sidebar, white content tab, graphite #383838 actions, #DEDEDE hairlines, 8 px controls, 14 px panels, SF system type, the folded-cap companion in graphite outline. Status dots (pulse = working, red = needs you, green = done) and DESIGN.md's green +N / red −N diff counts are the only colour. Demos sit directly on the white tab, never in a tray.

STORY: The visitor sees the sidebar running agents, reads that agents work in real tabs and wait for approval, follows the features tab by tab, and downloads from the always-visible dock.

FIRST VIEWPORT: Full-height sidebar at left (Lima mark, feature tabs, a Workspaces folder whose demo rows animate, Download dock pinned at the bottom). The content tab at right: a large headline, one sentence of copy, the Download button with version, and the companion handing a typed request to the "Client Website" workspace, which lights up in the sidebar.

FORM: A sidebar-navigated Lima window, pinned whole by the user's steer after a structures round; position 1 of 1 once pinned. seed: none (pinned) "Let's do a combo where there is the whole sidebar, but you use the features-guided, to navigate the website. It should remain easy to download"; world pinned by the user's answer "Stay graphite/white" and the established DESIGN.md world. Signature interaction: the site's own sidebar plays the product. Scrolling selects the feature tab with Lima's activity mark, and the demos drive the sidebar's workspace rows. Motion grammar: Lima's companion keyframes and status-dot pulses, exponential ease-out, nothing else.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
