Lima

A browser and AI workspace for macOS. Agents work in the same tabs and terminals you do, and you can always see what each one is doing.

Install

  1. Open Lima.dmg and drag Lima to Applications.
  2. The first time, Control-click Lima in Applications and choose Open. Lima is signed with its own certificate rather than through Apple’s notary service, so macOS asks once.
  3. After that, Lima updates itself. Each update is checked against a signed release feed and Lima’s certificate before it installs.

Requirements

macOS 14 or later, Apple Silicon or Intel. AI features use the Claude Code, Codex or OpenCode CLI you already have.
